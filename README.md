# Scrittapp - Segundo Cerebro & Productividad

Scrittapp es una aplicación integral de productividad diseñada para funcionar como un "Segundo Cerebro". Permite gestionar metas, hábitos y un diario personal con una estética premium y minimalista.

## 🚀 Estructura del Proyecto

- **/frontend**: Aplicación React + Vite + Tailwind CSS.
- **/backend**: Servidor Node.js + Express con base de datos SQLite.

## ✨ Funcionalidades Principales

- **Dashboard:** Heatmap de 14 días con estadísticas de racha.
- **Gestión de Metas:** Define objetivos booleanos, por cantidad o con fecha límite.
- **Hábitos:** Vinculación de hábitos a metas con tipos de medición específicos (Tiempo, Cantidad, Check).
- **Diario (Vault):** Editor tipo Notion con barra de herramientas flotante y auto-guardado.
- **Calendario:** Vistas de Mes, Semana y Día integradas con actividad y diario.
- **Modo Claro/Oscuro:** Sistema de temas con estética cuidada (Cream Light Mode).

## 🛠️ Instalación

### Requisitos
- Node.js (v18+)
- npm o yarn

### Backend
```bash
cd backend
npm install
node server.js
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
